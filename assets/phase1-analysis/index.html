مشروع تخرج 2026/2027 — SmartEvent

Phase 1 — Analysis

هذه البوابة تجمع مخرجات مرحلة التحليل لمشروع SmartEvent: منصة AI-Powered لإدارة دورة حياة الفعاليات (اكتشاف، تذاكر QR، سوق B2B، تحليلات لحظية).

مخرجات Phase 1

1. Requirements

متطلبات وظيفية FR وغير وظيفية NFR لكل وحدة في المنصة.

2. User Stories

قصص Attendee، Organizer، Execution Company، Super Admin.

3. Database Design

6 domains، ~30 جدول، MySQL + Prisma، تطبيع 3NF.

4. API Contracts

REST + WebSocket + AI internal endpoints.

5. AI Requirements

NLP، توصيات هجينة، logistics، vendor matching.

الفاعلون الأربعة

  • Attendee — اكتشاف AI، حجز، QR wallet، تقييمات.
  • Event Organizer — بناء فعالية، بوابات QR، RFQ، analytics.
  • Execution Company — خدمات، تحقق، عروض أسعار، عقود.
  • Super Admin — موافقات، تحقق شركات، مراقبة مالية.

Stack التقني (من المخططات)

  • Frontend: React.js، TypeScript، Tailwind CSS، Vite
  • Backend: Node.js، Express.js، TypeScript، Prisma، Socket.IO
  • Database: MySQL
  • AI: Python 3.11، FastAPI، NLP + ML scoring

Golden Rule — No Business Authority (§9)

الذكاء الاصطناعي لا يمتلك أي سلطة تنفيذية تجارية إطلاقاً:

الـ AI يقترح فقط (Suggestion) → الـ Node.js Backend يتحقق من القواعد والصلاحيات (Validation) → المستخدم يؤكد الإجراء يدوياً (Confirmation) → التنفيذ الفعلي في النظام.
