Gate Validation Logic

Step-by-step verification pipeline from scanner scan to door release:

1. Scanner Optical Capture & Decode
  • Extract signed token and cryptographic payload
  • Validate against server hash secret
2. Fork / Join Execution (On Valid Ticket)
  • Record check-in timestamp in Database
  • Update status to USED (Prevents reuse)
  • Broadcast real-time headcount counter via WebSocket
  • Green Light: Access Granted
3. Invalid / Duplicate Handling
  • Token expired, tampered, or already checked-in
  • Red Light: Access Denied with detailed reason
